# CSS v0.4

CSS в TelaOS: что из CSS имеет смысл на экране часов, что уже работает и во что оно превращается
в LVGL. Браузер без JS — всё остальное должно быть: HTML (`docs/HTML_TAGS.md`) и CSS.

## Changelog

- **v0.4**: Блок. `margin` (1–4 значения, отрицательные), `border` и стороны (`border-bottom`,
  `border-width`…), `outline` и `outline-offset`, `box-shadow`, `overflow` (`hidden`, `auto`, `scroll`,
  `visible`, по осям), `linear-gradient()` вдоль осей. `border: none` убирает и рамку, которую
  элемент рисует сам (`<fieldset>`).
- **v0.3**: Значения. Длины в `em`, `rem`, `vw`, `vh`; цвета `rgb()`, `rgba()`, `hsl()`, `hsla()`,
  `#RGBA`, `#RRGGBBAA` с прозрачностью; `transparent`; 1–4 значения в `padding`, два в `gap`,
  `row-gap`, `column-gap`; `border-radius: 50%` — круг; переменные `--x`, `var(--x, запасное)`, `:root`.
  Значение, которое не читается, выбрасывает объявление, как в браузере: раньше `color: rgb(1, 2)`
  давал чёрный, `font-size: inherit` — 16px, а `padding: 4 8` — 48.
- **v0.2**: `<label>` и `<button>` с HTML внутри — предки этого HTML: `.x i {}` красит `<i>`
  в `<label class="x">`.
- **v0.1**: Список CSS для часов. Селекторы и каскад: списки `a, b`, потомок `nav a`, дочерний
  `ul > li`, `*`, атрибуты `[a=v]` (и `~= |= ^= $= *=`, флаг `i`), страница как предок,
  специфичность, `!important`, `display: none` из листа, правила для строчных элементов.
  Разбор: `;;` и объявление без `:` больше не вешают часы (прежний разбор на них зацикливался),
  `;` в кавычках не обрывает объявление, комментарии внутри блока пропускаются.

## Где живут стили

- `<style>` в `<app>` — для всего приложения; `<style>` на странице — для того, что после него.
- `style="…"` у элемента — после всех листов.
- Атрибуты TelaOS (`bgcolor=`, `color=`, `font=`…) — после CSS: виджет ставит их сам.
- Движок: `src/ui/css_parser.cpp`. Предки элемента для селекторов — `UI::CssScope`: страница,
  `<div>`, таблицы, вкладки, `<label>` и `<button>` с HTML внутри и элементы HTML, пока строится их содержимое.

## Значения

- Значение, которое не читается, выбрасывает своё объявление — как в браузере. Свойство тогда
  наследуется или остаётся как было: `color: rgb(1, 2)` не красит в чёрный, `font-size: inherit` не
  сбрасывает шрифт на 16px.
- Длины: число без единиц или `px`, `em`, `rem`, `vw`, `vh`. Шрифт берётся ближайший сверху из
  шрифтов прошивки (16, 32, 48, 72), и `em` — это он.
- Прозрачность цвета — `text_opa` для `color` и `bg_opa` для фона. `transparent` и
  `background: none` убирают фон.
- `--x: …` — переменная: её видят элемент и всё внутри него, `:root { --x: … }` — все.
  `var(--x, запасное)` берёт ближайшую; если её нет и запасного нет, объявление выбрасывается.
  Переменные, которые ссылаются друг на друга по кругу, недействительны.

## Строчные элементы

У слов внутри абзаца (`<a>`, `<span>`, `<b>`) нет своих объектов LVGL: это куски одной надписи или
группы спанов. Правила для них (`nav a`, `.menu a`, `a.btn`) дают то, что умеет кусок текста:
`color`, `font-size`, `text-decoration`.

## Ограничения

- Правило с потомком действует на элементы, которые строятся после `<style>`, как и любое правило
  на странице.
- Когда `class="{var}"` меняется, перечитываются только правила из одних классов — как и раньше;
  `var()` в них видит только свои переменные и `:root`.
- `:root` — для переменных: другие свойства в `:root` ни на что не действуют (страница — не элемент
  со стилем), `:root .x` не срабатывает.
- `rem` — всегда 16px: `html { font-size }` его не меняет.
- `em` и `%` в `font-size` строчного элемента — от шрифта строчного элемента вокруг или блока по
  умолчанию (`h1` — 48px); `font-size` самого блока из CSS тут не учитывается.
- `border-radius` в процентах — только круг (50% и больше): размер элемента в это время ещё не известен.
- `<th>` строится как `<td>`: правила `th` к нему не применяются.
- `margin` действует там, где раскладывает LVGL: в потоке HTML и во flex. У TelaOS-виджета
  с `x`/`y` его нет. `margin: 0 auto` не центрирует.
- У рамки одна толщина и один цвет: если стороны заданы разными, берутся у стороны, заданной
  последней. `dashed`, `dotted`, `double` и другие стили рисуются сплошной линией.
- `box-shadow: inset` не рисуется: LVGL рисует тень только снаружи.
