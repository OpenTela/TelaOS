# HTML Tags v0.13

Стандартные HTML-элементы в TelaOS: все элементы справочника MDN
([HTML elements reference](https://developer.mozilla.org/en-US/docs/Web/HTML/Reference/Elements)),
что с каждым делает движок, и как это проверяется.

## Принцип

1. **TelaOS-теги работают как раньше.** `label`, `button`, `div`, `table`… с `x`/`y`/`align` стоят там,
   где сказано. Приложение без HTML-тегов строится байт в байт как прежде (проверено скриншотами всех
   приложений из `data/apps`).
2. **HTML-теги текут, как в браузере.** Блоки идут сверху вниз, строчный текст переносится по словам.
3. **Контейнер с HTML становится страницей браузера.** Если в `<page>` (или в `<div>`, `<tab>`)
   есть HTML — текст или стандартный элемент, — у него появляется один корневой блок потока
   (отступ 8px, шрифт 16px, белый), страница прокручивается по вертикали. TelaOS-виджеты **без**
   `x`/`y`/`align` встают в этот поток по порядку; **с** координатами — остаются на своих местах.
4. **Размеры и строки — браузера, цвета — как у `<markdown>`.** Заголовки — от размера текста вокруг, как в
   браузере; строка каждого размера — та, что даёт браузер (`line-height: normal`). Размеров шрифта 12, от 12 до 72:
   16, 32, 48 и 72 — во flash; остальные, жирное начертание, курсив и иконки — файлами на LittleFS
   (`data/system/fonts/`).

| Что | Вид |
|-----|-----|
| `h1` | 2em (32px в тексте 16px), жирный, `#FFFFFF` |
| `h2` | 1,5em (24px), жирный, `#DDDDDD` |
| `h3`, `h4`, `h5`, `h6` | 1,17em (18px), 1em (16px), 0,83em (14px), 0,67em (12px), жирный, `#DDDDDD` |
| `b`, `strong`, `th` | жирный |
| `a[href]`, `dt` | `#4FC3F7` (ссылка ещё и подчёркнута) |
| `em`, `i`, `cite`, `var`, `dfn`, `address` | курсив |
| `small`, `sub`, `sup`, подписи | `#AAAAAA` |
| `code`, `kbd`, `samp`, `tt` | `#81C784` |
| `mark` | `#FFD54F` |
| `u`, `ins` / `s`, `del`, `strike` | подчёркивание / зачёркивание |

```html
<page id="main">
  <h1>Погода</h1>
  <p>Сегодня <b>+3°</b>, ветер <i>слабый</i>. <a href="/week">На неделю</a></p>
  <ul>
    <li>Утром туман
    <li>Днём солнце
  </ul>
  <button onclick="refresh">Обновить</button>   <!-- без x/y: встаёт под списком -->
</page>
```

## Все элементы справочника MDN

Статус — по MDN: актуальный, экспериментальный, устаревший. «TelaOS» — родной виджет движка
(поведение не менялось). Остальное отрисовывает слой `src/ui/ui_html_flow.cpp`.

### Корень, метаданные, разделы

| Элемент | Статус | В TelaOS |
|---------|--------|----------|
| `html`, `body` | актуальный | прозрачны: содержимое идёт в поток |
| `head`, `title`, `base`, `link`, `meta` | актуальный | не отображаются (как в браузере) |
| `style` | актуальный | CSS разбирается и применяется к следующим элементам |
| `address` | актуальный | блок, курсив |
| `article`, `aside`, `footer`, `header`, `main`, `nav`, `section`, `search`, `hgroup` | актуальный | блоки |
| `h1`–`h6` | актуальный | заголовки (размеры выше) |

### Текстовые блоки

| Элемент | Статус | В TelaOS |
|---------|--------|----------|
| `p` | актуальный | абзац; без `</p>` закрывается следующим блоком |
| `div` | актуальный | **TelaOS**; прямой текст в нём теперь виден, без `w` в потоке — на всю ширину |
| `blockquote` | актуальный | отступ и линия слева |
| `pre` | актуальный | пробелы и переводы строк сохраняются |
| `hr` | актуальный | линия 1px |
| `ul`, `ol`, `menu`, `li` | актуальный | маркеры `•` `–` `›` по глубине; `ol`: `start`, `type="1 a A i I"`, `reversed`, `li value`; `</li>` можно опустить |
| `dl`, `dt`, `dd` | актуальный | термин (акцент) и определение (отступ); `</dt>`/`</dd>` можно опустить |
| `figure`, `figcaption` | актуальный | блок с отступами, подпись приглушена |

### Строчная семантика

| Элемент | Статус | В TelaOS |
|---------|--------|----------|
| `a` | актуальный | `href="/page"` — переход, `href="#id"` — прокрутка к элементу, `href="…://…"` — в лог (на часах не открывается); `onclick="fn"` — Lua |
| `b`, `strong`, `i`, `em`, `u`, `s`, `mark`, `small`, `code`, `kbd`, `samp`, `var`, `cite`, `dfn` | актуальный | начертание, цвет или линия по таблице выше |
| `sub`, `sup` | актуальный | приглушены; `sup` на треть строки выше, `sub` на пятую часть ниже, строка даёт им место |
| `q` | актуальный | в кавычках “ ” |
| `ruby`, `rt`, `rp` | актуальный | `rt` в скобках после основы, `rp` пропускается |
| `abbr`, `bdi`, `data`, `time`, `span` | актуальный | обычный текст (`style="color:…"`, `class` дают цвет) |
| `bdo` | актуальный | `dir="rtl"` — буквы справа налево: `<bdo dir="rtl">olleH</bdo>` — «Hello» |
| `br`, `wbr` | актуальный | перевод строки / ничего |
| `del`, `ins` | актуальный | зачёркнут / подчёркнут |

### Изображения, медиа, встраивание

| Элемент | Статус | В TelaOS |
|---------|--------|----------|
| `img` | актуальный | TelaOS `<image>`: `src`, `width`/`height`, `id`, `onclick`; без `src` или без файла — текст `alt` (на месте картинки, с её размером, `onclick` и `visible`) |
| `picture`, `source` | актуальный | берётся вложенный `img` |
| `video`, `audio`, `iframe`, `object`, `embed` | актуальный | запасное содержимое, если есть; иначе рамка `[video]` с `title`/`alt` |
| `fencedframe` | экспериментальный | как `iframe` |
| `svg`, `math` | актуальный | рамка `[svg]` / `[math]` |
| `canvas` | актуальный | **TelaOS** `<canvas>`; размер — `width`/`height`, как в HTML, или `w`/`h`; без них 200×200 |
| `map`, `area`, `track` | актуальный | не отображаются |
| `noscript` | актуальный | не отображается (скрипты в TelaOS есть) |
| `script` | актуальный | в странице не отображается (скрипт приложения — `<script>` в `<app>`) |

| Элемент | Статус | В TelaOS |
|---------|--------|----------|
| `table`, `tr`, `td` | актуальный | **TelaOS**; прямой текст в `<td>` теперь виден; `colspan="2"` — ячейка занимает две доли строки, как две ячейки |
| `th` | актуальный | как `<td>` (и `colspan`), жирный и по центру |
| `caption` | актуальный | подпись над таблицей, по центру |
| `thead`, `tbody`, `tfoot` | актуальный | прозрачны: строки идут в таблицу |
| `col`, `colgroup` | актуальный | не отображаются |

### Формы

| Элемент | Статус | В TelaOS |
|---------|--------|----------|
| `form`, `fieldset`, `legend` | актуальный | блок; `fieldset` — рамка, `legend` приглушена; `<fieldset disabled>` выключает все поля и кнопки внутри |
| `input` без `type` | — | **TelaOS** `<input>` (как раньше) |
| `input type="text"` (и `email`, `search`, `tel`, `url`, `number`, `date`…) | актуальный | TelaOS-поле: `bind`, `placeholder`, `value`, `maxlength`, `readonly` (текст виден, клавиатура не открывается), `disabled`, события |
| `input type="password"` | актуальный | поле с `password="true"` |
| `input type="checkbox"`, `"radio"` | актуальный | флажок: `checked`, `disabled`, `bind` ("true"/"false"), `onchange`; радио — группа по `name` |
| `input type="range"` | актуальный | TelaOS `<slider>`: `min`, `max`, `step` (ползунок встаёт на min + k·step, `value` тоже), `value`, `bind`, `disabled` |
| `input type="submit"`, `"reset"`, `"button"` | актуальный | TelaOS `<button>` с текстом `value`, `onclick`, `disabled` |
| `input type="image"` | актуальный | как `img` |
| `input type="hidden"` | актуальный | ничего |
| `textarea` | актуальный | многострочное поле, содержимое — начальный текст, `rows` → высота, `maxlength`, `readonly`, `disabled` |
| `button`, `label`, `select`, `option` | актуальный | **TelaOS**. `<label for="id">`: тап по подписи — как тап по полю (флажок переключается, радио включается, поле открывает клавиатуру, список раскрывается). `<option selected>` — выбран сразу, если `bind` не задаёт другое; `<option disabled>` выбрать нельзя; без них выбран первый доступный. `</option>` можно не писать. HTML внутри `<label>` и `<button>` — как в браузере: `<label>Имя <i>(необязательно)</i></label>`, `<button><b>Сохранить</b> сейчас</button>`; поле внутри подписи (`<label><input type="checkbox"> Запомнить</label>`) работает от тапа по её тексту; `<img>` в кнопке — её иконка |
| `optgroup`, `datalist` | актуальный | не отображаются |
| `selectedcontent` | экспериментальный | внутри `<select>` игнорируется |
| `progress` | актуальный | полоса 160px: `value`/`max` |
| `meter` | актуальный | полоса 80px: `min`, `max`, `low`, `high`, `optimum`. `low` и `high` делят шкалу на три части: в части с `optimum` полоса зелёная, в соседней — жёлтая, в дальней — красная. Без `optimum` — середина шкалы, то есть вне `[low, high]` жёлтая |
| `output` | актуальный | обычный текст |

## Разбор

- **Пустые элементы** (`br`, `hr`, `img`, `input type=…`, `meta`, `link`, `source`, `track`, `wbr`,
  `col`, `area`, `base`, `embed`, `param`) не требуют `/>` и не ломают разбор `<state>`/`<script>`.
- **Опущенные закрывающие теги**: `li`, `dt`, `dd`, `p`, `td`, `th`, `tr`, `thead`, `tbody`, `tfoot`,
  `rt`, `rp`, `option`, `optgroup` закрываются следующим соседом (`<li>a<li>b`, `<td>1<td>2`,
  `<p>текст<div>` — абзац кончается перед блоком) или концом родителя.
- **Неизвестные теги** (`<my-widget>`, `<blink>`) показывают содержимое, как в браузере.
- **Сущности**: `&amp; &lt; &gt; &quot; &apos; &nbsp; &copy; &reg; &deg; &plusmn; &times; &laquo;
  &raquo; &ndash; &mdash; &lsquo; &rsquo; &ldquo; &rdquo; &bull; &euro; &pound;…` и числовые `&#8364;`,
  `&#x41;`.
- **Знаки шрифтов прошивки** (Ubuntu, 650 знаков в каждом размере): латиница всех европейских
  языков (`ä ß é ñ ą ł č ř ő ș ț ə`), греческий, кириллица (`Ґ`, казахская, татарская…), знаки
  `– — … ‘ ’ “ ” „ • ‹ › « » € ₴ № ™ © ® ° ± × − ≈ ≠ ≤ ≥ ∞ √ ‰`. Знаки, которых нет у первого
  шрифта, рисует второй шрифт того же начертания и размера (`UbuntuExt_*px`, `scripts/make_fonts.py`).
  Знаки `← → ↑ ↓ ✓ ★ ☆ ♥ ♡ ⚙ ☀ ☁ ▶ ⏸` и ещё 43 рисует шрифт иконок (`docs/ICONS.md`).
- **Иконки по имени**, как у Google: `<span class="material-symbols-outlined">home</span>`,
  `<i class="material-icons">home</i>`. 179 имён; 24px, пока страница не задаст `font-size`;
  `{var}` вместо имени тоже работает. Неизвестное имя остаётся текстом. Подробно — `docs/ICONS.md`.
- **Пробелы** схлопываются (кроме `pre`, `listing`, `textarea`).
- **Комментарии** `<!-- … -->` пропускаются целиком, даже с `>` внутри.
- **Цвета**: `#RGB`, `#RRGGBB` и все 148 имён CSS (`teal`, `orange`, `rebeccapurple`…) — в атрибутах,
  в `<style>` и в `style="…"`. Неверный цвет (`color="notacolor"`) игнорируется.

## Живые значения

`{var}` работает в любом тексте, в том числе внутри форматирования:

```html
<p>Счёт: <b>{score}</b> из {total}</p>
```

`id` у элемента адресует его для `ui.setText()`, `visible="{var}"` и ссылок `href="#id"`.
`ui.setText()` у абзаца меняет текст, у `<li>` — текст пункта (маркер остаётся), у блока
(`section`, `div` с текстом, `dialog`) — всё содержимое, как `textContent` в браузере; у полосы,
линии, картинки — ничего не делает.

## Направление: `dir`

`dir="rtl"` у любого элемента — и у `<html>`, `<body>`, TelaOS `<div>`, `<table>`, `<td>`:

- строки прижаты вправо;
- столбцы таблицы и маркеры списков идут справа налево;
- отступ вложенного списка, `dd` и линия `blockquote` — справа.

Порядок слов не меняется. В шрифтах часов нет букв, которые пишутся справа налево, а латиница и
кириллица и в RTL-абзаце идут слева направо — как в браузере. `dir="ltr"` отменяет `rtl` внутри;
`dir="auto"` для этих букв — `ltr`.

## Ограничения

- Нет блочной модели CSS (`margin`, `float`, `position`): отступы фиксированы (блоки 8px, список 4px).
- В `dir="rtl"` знаки препинания на краях абзаца остаются на месте; браузер переносит их по алгоритму bidi.
- `{var}` внутри `<bdo dir="rtl">` остаётся живым, но его значение не разворачивается.
- В строке со ссылками, полем или `sup`/`sub` значение `{var}` переносится целиком, а не по словам.
- `id` у строчного элемента внутри текста (`<span id>`) не адресуется: у него нет своего объекта.
- Подпись с HTML внутри — одна строка по ширине текста, если у неё нет `w`. Ссылка внутри такой подписи
  делает ссылкой всю подпись, когда в строке нет полей.
- `<option disabled>` в раскрытом списке выглядит как остальные: выбрать его нельзя, но он не серый
  (у списка LVGL один стиль на все пункты).
- SVG, MathML, видео и звук не воспроизводятся — только запасное содержимое или рамка.
- `rowspan` не работает: строка таблицы — ряд flex, ячейка не может занять две строки (сетки LVGL в
  прошивке нет, `LV_USE_GRID 0`). С `cellspacing` границы ячеек со `colspan` и без него чуть
  расходятся: на долю зазора.
